Reference

{% svg 'mplate-7079-form' %}
  • CCCCCCCC: shortened chassis number. Enter without spaces.
  • E: optional "E", indicates manufacture at the Emden plant.
  • M01: M-codes, first row. Separated by spaces. Might be empty in some plates.
  • PPPPII: paint and interior code.
  • M02: M-codes, second row. Separated by spaces.
  • DDD: production date. Enter without spaces.
  • UUUU: production planning code. It will not be decoded.
  • XXX: export destination. Two-letter code for worldwide exports. Three-digit or none for German market.
  • TTTT: vehicle model type.
  • AA: aggregate code
